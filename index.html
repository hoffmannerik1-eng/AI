KI-Einstellungen

Die Website selbst braucht keinen Schlüssel. API-Keys, die im Browser eingegeben werden, sind aber nicht geheim. Für eine öffentliche Website ist ein geschütztes Backend besser.

Lokales Modell auf dem PC

Ollama kann lokal laufen. GitHub Pages kann nicht automatisch darauf zugreifen. Für dein iPad muss der PC-Endpunkt im WLAN erreichbar und für die Website freigegeben sein. Öffne keinen lokalen KI-Server ungeschützt im Internet.

Der Verlauf wird in diesem Browser gespeichert. Er synchronisiert sich nicht automatisch zwischen iPad und PC.
